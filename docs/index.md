# Sd Developer Guide

This guide is for the people who work on Sd: how the project is built, tested,
and checked. The manuals for callers are the Texinfo files in `doc/`; this
guide does not repeat them.

Sd is developed in two repositories that are used together. The public `sd`
repository holds the source and the manuals, and the private `sd-regression`
repository holds the regression suite. `CONTRIBUTING.md` is the short version
of this guide.
